# Student Information System

A modular Student Information System developed in C for the CSE102 course.

## Features

- Student Management
- Professor Management
- Course Management
- Enrollment Management
- Grade Management
- GPA Calculation
- CSV File Storage
- Modular Design
- Linked Lists
- Dynamic Memory Management

## Technologies

- C
- Linked Lists
- File I/O
- Dynamic Memory Allocation
- Makefile
